A program that writes one sentence to `/output/entry.txt`, for the
make.fun competition
[A Day of One-Line Pitches](https://make.fun/bounty/u-ronigrv-a-day-of-one-line-pitches-12cd9bb3).

Run it with Python 3:

```
python3 main.py
```

It writes the pitch below to `/output/entry.txt` (or to the path given as
the first argument, or `$OUTPUT_PATH`). No network, no clock, no
randomness. The pitch is one sentence of 193 characters, inside the 1 to
240 gate.

## The pitch

```
Your idea is already good enough, so describe it in plain words on make.fun today and an AI agent will turn it into your first real app for free, with you in charge and no coding needed at all.
```
